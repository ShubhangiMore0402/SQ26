## Overview

This project is a two-stage pipeline for harvesting, seeding, classifying, and exporting qualitative research datasets from open repositories.

1. **Part 1: Acquisition and Seeding**  
   `23137504-seeding.ipynb` queries the Zenodo and Harvard Dataverse APIs, downloads qualifying project files, and writes metadata into `23137504-sq26.db`.

2. **Part 2: Semantic Classification**  
   `23137504-classification.ipynb` copies the seeded data into a classification database, assigns `PROJECT_TYPE`, embeds project text with sentence-transformers, maps each project to ISIC Rev.5 divisions, and exports XLSX and PDF reports.

## What the pipeline does

- Detects QDA project containers using file extensions such as `qdpx`, `nvp`, `nvpx`, `mx24`, `atlproj`, `qde`, and related formats.
- Falls back to primary data files such as documents, spreadsheets, text files, audio, video, and images when no QDA container is present.
- Stores metadata, keywords, people/roles, and licenses in SQLite.
- Classifies both project-level records and primary files using ISIC Rev.5 division labels.
- Generates a classification database, spreadsheet export, and PDF report.

## Running the notebooks

### Part 1: Acquisition

Open `23137504-seeding.ipynb` and run it top to bottom. The notebook supports a dry-run mode for testing and a real-download mode for building the dataset.

### Part 2: Classification

Open `23137504-classification.ipynb` and run it top to bottom. The notebook expects the seeding database from Part 1 and produces the classification database, XLSX export, and PDF report.

## Output files

Part 2 produces the following main outputs:

- `23137504-sq26-classification.db`
- `23137504-sq26-classification-results.xlsx`
- `23137504-sq26-classification-report.pdf`

## Notes on classification

The classification notebook uses sentence-transformer embeddings with an ISIC Rev.5 label set. Project text is built from the title, a cleaned description, and keywords. The notebook also includes a sanity gate so that obvious model failures are caught before classification continues.
